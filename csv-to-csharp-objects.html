Practical guide
How CSV to C# Objects works
The first row becomes property names and each later row becomes an object initializer. Generated properties use string values with empty-string defaults to preserve source data without type guesses.
Convert your file
Select a CSV or TSV file and enter a class name, then choose Convert. Headings are normalized to PascalCase properties and collisions receive a suffix.
Before using the output
Review property names, namespaces, and collection needs before using the output. Convert values to numeric or date types only when those types match the data and application rules. The code embeds data; it does not parse a CSV at runtime.
Frequently asked questions
Does it infer C# types?
No. Properties are strings unless you change them in your project.
Does the class parse CSV files?
No. It embeds selected rows as object initializers.
Can I customize the class name?
Yes. Set the class name in the field before converting.
