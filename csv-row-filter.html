ROW FILTER GUIDE

Narrow a CSV to the records you need

When a spreadsheet export contains hundreds or thousands of records, scanning for one status or threshold by eye is a poor way to make a smaller working file. A row filter checks one chosen column and builds a new CSV from the records that meet your condition. It is useful for pulling out open orders, finding rows with missing contact details, or isolating transactions above a chosen amount before you review them.

You can keep matching rows or remove them. For example, keep records whose Status contains “open” to prepare a follow-up list. Choose remove matches with the same condition to exclude those records and retain the other statuses. The first row remains the header either way.

Pick a condition that fits the field

For labels or names, use Contains to find a word within a cell or Equals when the whole cell should match. Text comparisons ignore case by default, with an option to distinguish uppercase and lowercase. For numeric columns, Greater than and Less than compare numeric values, including decimals; text such as a currency symbol is not converted automatically. Choose Is empty or Is not empty to check for missing entries.

The condition applies to one column at a time. It does not combine multiple rules such as “Status is Open and Amount is over 100.” If you need a second pass, download or paste the first result and filter that result again.

What happens to the other data?

A matching row is kept or removed as a whole. Its other fields stay together, and retained records keep their source order. The tool does not sort columns, edit cell values, or change the uploaded file. The result includes the original headings—even if no data rows match—so it remains a valid table structure.

Filter and check your records

  1. Upload a CSV, TSV, or delimited TXT file, or paste rows.
  2. Select the field and condition. Enter a value unless you chose an empty-cell check.
  3. Choose whether to keep matching records or remove them, then apply the filter.
  4. Review the full result table and copy or download the new CSV.

Comma, tab, semicolon, and pipe separators are detected. Quoted values can include separators, quotation marks, and line breaks. The result downloads as comma-separated CSV. Files up to 50 MB are processed in your browser and are not uploaded to RomitCSV.

Questions about filtering CSV rows

Does row filtering delete records from my original file?

No. It creates a separate result. Your uploaded file is unchanged, and you can choose to keep matches or remove matches in that result.

How are greater-than and less-than checks evaluated?

The selected cell and search value must both be numeric. Values such as 12.5 or -3 are compared numerically; blank cells and non-numeric text do not qualify.

Are text comparisons case-sensitive?

No, they ignore case by default. Turn on Match case when uppercase and lowercase should be treated differently.

Will the output include the header?

Yes. The source heading row is preserved, including when no data rows satisfy the condition.

Can I filter by more than one column at once?

This tool applies one condition to one column per run. Apply another pass to the result if you need to narrow it further.

Can I find rows with missing values?

Yes. Choose the column and use Is empty to keep blank cells or Is not empty to keep rows with a value.

Is my file uploaded?

No. The filter runs in your browser.
