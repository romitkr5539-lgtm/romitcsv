Find blank cells in your CSV
Missing values can affect formulas, imports, charts, and reports. They are easy to overlook in a large table, especially when blanks appear in only a few rows. The CSV Missing Values Checker scans each column, counts empty cells, and lists the row numbers where you may want to review the data.

    
What counts as a missing value?
A cell is counted as missing when it is empty or contains only whitespace such as spaces or tabs. A value like 0, false, or N/A is treated as present because it contains text. If your data uses a marker such as N/A to mean “not available,” this checker does not reinterpret that marker automatically.

    
What the report shows
  • Missing cells: total number of blank cells found across the checked columns.
  • Columns with blanks: number of columns containing at least one missing value.
  • Missing values per column: count beneath each first-row heading.
  • Affected row numbers: data row numbers, based on the original CSV line numbering that includes the header. The report lists up to 100 rows per column.

    
The first row is treated as column headings and isn’t counted as data. Row numbers start at 2 for the first data record. If a file has more than 100 missing cells in one column, the count still includes them all, while the row list is capped at 100 for a compact report.

    
How to check for missing CSV values
  1. Choose or drop a CSV, TSV, or plain-text file up to 50 MB, or paste delimited data.
  2. Check the source table preview and confirm the header row.
  3. Review the missing-cell totals and row locations by column.
  4. Copy or download the report, then decide how you want to fill or preserve the blanks.

    
The checker only reports missing values; it does not fill cells or alter the source file. Data is processed in your browser and is not sent to the RomitCSV server. To check row widths, quote syntax, or headers, use the CSV Validator.

    
Frequently asked questions
Does zero count as a missing value?
No. A cell containing 0 is present. Only empty and whitespace-only cells are counted as missing.
Does the tool treat N/A or NULL as blank?
No. These are text values, so they count as present. The checker does not guess whether a text marker has a special meaning in your dataset.
Are cells containing spaces considered missing?
Yes. A cell that contains only whitespace is treated as empty. Spaces around a non-empty value do not make that cell missing.
Why does the report stop listing rows after 100?
To keep the report readable, it lists at most 100 affected row numbers per column. The missing-value count still includes all matching cells.
Is the header row included?
No. The first row is used as the column names. Data row numbering starts at row 2 of the CSV, immediately after the header.
Will this fill in the missing data?
No. It identifies blanks but does not guess replacement values or modify your CSV.
