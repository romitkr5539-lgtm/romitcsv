Merge CSV Files into One Dataset

When data is split across monthly exports, regional reports, or separate contact lists, merging the files puts the records into one table. This CSV merger appends the data rows from each file and lets you decide how it lines up the columns. You can add several files at once, drop more onto the preview later, remove a file you no longer want, and review the combined rows before downloading.

Each file’s first row is treated as its column headings. Those heading rows are used to organize the output; they are not repeated as data rows. The rows underneath are kept in source-file order, and the original files are left unchanged.

Match columns by heading name

This option is on by default. It is useful when two exports contain the same fields in a different order. The merger reads the headings, then places each value under its matching name instead of blindly copying it into the same numbered position.

The first file establishes the starting order of the output headings. If a later file contains a heading that has not appeared yet, the merger adds that column at the end. If a file has no matching column, the cells for those rows are left blank. The rows are still appended, so a missing field does not shift the values in neighboring columns.

FILE ONE
Name,Email,City
Sam,sam@example.com,Leeds
FILE TWO
City,Name,Email
York,Ana,ana@example.com
MERGED TABLE
Name,Email,City
Sam,sam@example.com,Leeds
Ana,ana@example.com,York

Heading matching is exact. Email, email, and Email are three different names because the capitalization or spacing differs. The merger does not infer that headings such as Customer and Customer Name refer to the same field. Rename inconsistent headings first if they should become one output column.

Combine columns by position

Turn off Match columns by header name when each file uses the same column order, or when a file has no meaningful header row. In position mode, values from column one are placed under the first file’s first heading, values from column two under its second heading, and so on. The first file supplies the output headings; additional positions found in later files are included as extra columns.

Position matching does not check whether the headings describe the same information. If one file is ordered Name,Email,City and another is City,Name,Email, their values will be put under the wrong headings in this mode. Keep header matching on for that situation.

Add files, review the result, and download

  1. Choose or drop two or more CSV, TSV, or TXT files. Each file can be up to 50 MB.
  2. Choose header matching or position matching before or after loading the files. The preview updates when you change this setting.
  3. Check the source-file list and row counts. Use Add more files or drop additional files onto the preview to include them; remove a listed file with its × button if it should be excluded.
  4. Review the merged table, then select Download Merged CSV. The download becomes available once at least two files are loaded.

The preview shows ten data rows per page and provides page controls for the rest. Files can contain commas, line breaks, or quotation marks inside quoted fields; those values stay in their cells. Blank data rows are preserved. The merged download is always comma-separated CSV, including when the input is TSV, semicolon-delimited, or pipe-delimited text.

Know what the merger does with your data

Merging appends records; it does not remove duplicate rows, sort the result, or decide which file is newer. If two files contain the same customer record, both copies remain. Files are appended in the order they were added. If you need a different order, remove the files and add them again in the sequence you want. The preview lists the files in merge order so you can check it.

The merger reads the files in your browser and creates a new download. It does not send the contents to the RomitCSV server or modify the original files. If a file has an unmatched quotation mark, the merger reports a formatting error instead of producing a partial result.

CSV MERGER FAQ

Questions About Merging CSV Files

Can I merge files when their columns are in a different order?

Yes. Keep Match columns by header name selected. Values are placed under matching headings rather than copied into the same numbered position.

Which file supplies the headings?

The first file supplies the initial heading order. With header matching on, new headings found in later files are added after those first headings.

What happens when a file is missing a column?

The merger leaves that field blank for rows from that file. Other values stay under their matching headings.

Are matching headings case-sensitive?

Yes. Headings must match exactly. Email, email, and Email are separate names.

Can I merge TSV or semicolon-delimited files?

Yes. CSV, TSV, and supported delimited TXT files are accepted. The combined result downloads as a comma-separated CSV.

Can I download after loading just one file?

No. One file can be previewed, but the merge download becomes available after you add at least one more file.

Can I add files after the first upload?

Yes. Select Add more files or drop the additional files onto the merge preview. You can also remove a source file before downloading.

Is there a file size limit?

Each selected file can be up to 50 MB.

Are my files uploaded?

No. Files are read and combined in your browser. The merger does not overwrite the source files.

Check the merged CSV before using it

Before importing the result into another system, scan the headings and a few rows from each source. Look for newly added columns, blank values where a file lacked a field, and headings that differ only by capitalization or spaces. If a value appears under the wrong heading, switch to header matching and review the preview again. The download contains a new combined CSV; your source files remain available as they were.
