Find repeated rows in a CSV file
Duplicate records can inflate counts, repeat transactions, or cause problems when data is imported into another system. The CSV Duplicate Checker compares each complete data row with earlier rows and reports later copies alongside the row where the same record first appeared.

    
How duplicate rows are compared
The first row is treated as the header and is excluded from the comparison. Every field in each data row is compared in order. The values must match exactly, including capitalization, spaces, blank fields, and the number of fields. For example, Ada,London and ada,London are different rows, as are Ada,London and Ada,London,.

    
The report counts each later occurrence as a repeated row. If the same record appears three times, the second and third occurrences are both listed and counted as duplicates, each pointing back to the first occurrence. The checker does not normalize text or remove records.

    
What the report shows
  • Data rows and columns compared: the number of records after the header and the header’s field count.
  • Repeated rows: number of later records that exactly match an earlier complete row.
  • First-seen rows: data row count minus repeated occurrences.
  • Matching records: first occurrence row, duplicate row, and the repeated field values.

    
Row numbers refer to CSV record positions, with the header as row 1 and the first data record as row 2. Blank records are compared like other records; repeated blank rows may therefore appear as duplicates.

    
How to check for duplicate rows
  1. Choose or drop a CSV, TSV, or plain-text file up to 50 MB, or paste delimited data.
  2. Review the source table and confirm the first row is the header.
  3. Check the repeated-row count and compare each reported row with its first occurrence.
  4. Copy or download the report if you need a record of the matches.

    
The checker reports duplicates but does not delete or change rows. Your data is processed in your browser and is not sent to the RomitCSV server. To find repeated column names or other file issues, use the CSV Validator.

    
Frequently asked questions
Does it compare only selected columns?
No. It compares the complete row, using every field and its position. Rows that match in some columns but differ in another are not duplicates here.
Are capitalization and spaces ignored?
No. Matching is exact. Differences in capitalization or whitespace make rows different.
Is the header row checked for duplicates?
No. The first row is treated as column headings and only rows beneath it are compared.
Why does a record appear more than once in the report?
Each repeated occurrence after the first is listed separately. If a row occurs three times, the second and third copies are both reported against the first.
Does the tool remove duplicate records?
No. It produces a report and leaves the original CSV unchanged. You can review the matches and decide which records to keep.
Are empty rows counted?
Yes. Empty data records are compared like other complete rows, so repeated empty rows can be reported as duplicates.
