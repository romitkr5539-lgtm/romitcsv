When the Same CSV Text Does Not Match

    
Two cells can look alike on screen and still contain different characters. A name copied from one system may have an accented letter stored as a base character plus a combining mark; another system may store the composed character. Extra tabs, line breaks, or spaces can also make an otherwise identical value fail a search or comparison.

    
Normalize CSV Data brings those common text differences into a consistent form. It applies Unicode NFC, changes each run of whitespace inside a field to one ordinary space, and removes whitespace from the field edges. It applies this to headings as well as data.


    

      
INPUT
  Full  Name  ,City
Ada	Lovelace, London
Maya
Chen,Paris

      
NORMALIZED
Full Name,City
Ada Lovelace,London
Maya Chen,Paris

    

    
The last example represents a line break inside one quoted CSV field. The parser keeps that field together, then normalization turns its line break into a space.


    
What Happens to Each Value

    
The transformation is the same for every cell, including the first parsed row:

    
    
      
  • Leading and trailing whitespace is removed.
    • 
      
  • One or more spaces, tabs, or line breaks inside the value become a single ordinary space.
    • 
      
  • Unicode characters are converted to NFC where a canonical composed form exists. For example, U+0065 U+0301 becomes U+00E9.
    • 
    

    
This does not change capitalization, translate text, remove accents, correct spelling, or convert a value into a number or date. NFC is not compatibility normalization: it does not broadly replace lookalike or full-width characters with different forms. Empty values stay empty, and the tool does not remove rows, duplicates, or columns.


    
Decide Whether Whitespace Carries Meaning

    
Normalization is useful when whitespace came from copying, inconsistent exports, or line wrapping and should not affect matching. It can also change a notes field where line breaks separate points: those breaks become spaces. Review the preview if a field uses spacing to show structure.

    
Headings are normalized too. A heading like  First Name  becomes First Name, which may help match a clean schema. If another system depends on the original spaces or exact Unicode sequence, keep a copy of the source and compare before importing the new file.


    
Use the Tool with Your Own File

    
Drop a CSV, TSV, or text file into the upload area, select Browse CSV File, or paste delimited data. Choose Normalize CSV Data and inspect the preview. The row and column counts show whether the table shape stayed the same; download the cleaned CSV only after the normalized text looks right.

    
Common comma, tab, semicolon, and pipe delimiters are detected. Quoted fields are parsed together, then the result is written as comma-separated CSV with quotes where needed. An unclosed quoted field causes an error. The tool does not repair uneven row lengths or check that headings match a schema.


    

      
NORMALIZE CSV DATA FAQ

      
Details That Affect Your Output

      
Does this make text lowercase or remove accents?
No. It keeps capitalization and accents. NFC composes canonically equivalent Unicode sequences when a composed form exists.

      
What happens to a line break inside a quoted cell?
The parser keeps it inside the same cell. The normalizer then converts that line break to a single ordinary space.

      
Are headings normalized too?
Yes. The first parsed row is processed just like the data rows, so heading edges and whitespace runs are changed too.

      
Will the tool remove blank rows or duplicates?
No. It normalizes the text in each field and keeps the parsed rows and columns in place.

      
Can I paste data or use a TSV file?
Yes. Paste delimited text or open CSV, TSV, and TXT files up to 50 MB. The result downloads as comma-separated CSV.

      
Are my file contents uploaded?
No. The file is read and processed in your browser; its contents are not sent to a server.

    


    
After You Normalize

    
The preview is shortened at about 7,000 characters for long files, while the download contains the full result. Your original is not overwritten. CSV output contains text values rather than spreadsheet formatting, formulas, or multiple worksheets.

    
If you only want to remove spaces at field edges, use Trim CSV Whitespace. To collapse repeated ordinary spaces without changing other whitespace or applying NFC, use Remove Extra Spaces. The CSV Validator can check the file structure separately.
