View, Search, Sort, and Edit a CSV Online

Use the CSV Viewer when you want to inspect a spreadsheet export without first opening a desktop spreadsheet app. It turns a CSV or TSV file into a table you can search and sort, and it lets you make quick changes to cell values. You can choose a file from your device or paste CSV text directly into the page.

Start with a File or Pasted CSV Text

Select Browse CSV File to open a CSV or TSV file, or drop the file into the upload area. If you already copied comma-separated text, expand Or paste CSV text, paste it in, and open it in the viewer. After the data loads, the file bar shows the name, number of data rows, and number of columns.

The first non-empty row is used for column headings. If a heading is blank, the table gives that column a label such as “Column 2.” It detects comma, tab, semicolon, or pipe separators from the first non-empty line and supports quoted fields. The viewer accepts files up to 50 MB. A completely blank line is not counted as a data row.

Find a Value, Then Narrow the Table

Enter a name, email address, product code, or other text in the search box. Search looks through every data cell, ignores capitalization, and matches partial text. For example, searching for alex can find Alex Morgan even when the value is in a column you are not looking at.

The viewer shows 50 rows per page and reports how many rows match. Use the arrows to move between pages. Select a column heading to sort the matching rows by that column; select the same heading again to reverse the order. Sorting changes the order shown in the table, but does not rearrange the source data in the download.

Make Cell Edits and Download the Full Dataset

Choose Edit cells to make table values editable. Click a cell, type the correction, then choose Save edits to leave edit mode. Changes are kept in the page while you work, including edits to rows found through search.

Choose Download CSV to save the updated dataset. The download includes all data rows, including rows outside the current page and rows hidden by the search. It does not save only the visible results. Download the file before leaving or refreshing the page if you want to keep your edits.

What to Expect from a CSV Table

CSV and TSV files store rows and text values; they do not carry spreadsheet colors, fonts, or workbook layout. The viewer displays cell contents as text and does not calculate formulas. If a cell contains a formula expression, it is shown as text rather than evaluated like a spreadsheet formula. Long or wide tables can be scrolled to inspect their contents.

Your selected file is processed in your browser and is not sent to a server by this tool. For larger files focused on finding values rather than editing them, use the Large CSV Viewer. If you need to add or remove rows and columns, use the CSV Editor.

Questions About Using the CSV Viewer

Can I view CSV data without installing a spreadsheet app?

Yes. Open a CSV or TSV file in the browser, or paste CSV text into the page, to view the records in a table.

Does search only check the current page?

No. Search checks all data rows. The table shows 50 matching rows at a time, and the arrows let you browse the rest.

Will the downloaded file include rows hidden by search?

Yes. Download CSV saves the full dataset, including rows that are not on the current page or do not match the search. It also includes your cell edits.

Does sorting change the order in my downloaded CSV?

No. Sorting changes the order displayed in the viewer. The downloaded CSV keeps the original row order and includes edits.

Can I use this page to edit a spreadsheet?

You can make quick edits to existing cells, but this viewer does not add or remove rows or columns and does not calculate formulas. Use the CSV Editor for broader changes.

Are my file contents uploaded?

No. This tool reads and processes the selected file in your browser; it does not send the file contents to a server.
