Practical guide
How CSV to Java Objects works
The first row provides property names. The output includes private string fields, a constructor, getters, and a static list containing one object per data row. Fields remain strings to avoid guessing at types.
Convert your file
Choose a CSV, TSV, or delimited file and enter a class name before converting. Column headings are normalized into Java-style identifiers; duplicate names receive suffixes.
Before using the output
The output uses List.of, which requires Java 9 or newer. It is a starting point, not a CSV parser; check class/package conventions and data size before adding it to a project.
Frequently asked questions
Are fields typed from their values?
No. The generated fields are strings so source values are preserved.
Does it include a CSV parser?
No. It embeds selected rows as Java objects.
Which Java version is needed?
The generated List.of call requires Java 9 or newer.
