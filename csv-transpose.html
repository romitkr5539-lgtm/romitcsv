TRANSPOSE GUIDE

Rotate a data layout when the columns should become rows

Some reports are easiest to read with one item on each row. Others arrive with categories down the left and dates across the top—or the reverse of the layout another spreadsheet or import expects. Transposing rotates the whole grid: every original row becomes a column, and every original column becomes a row.

For example, a compact monthly report might have a row for Sales and another for Returns, with January, February, and March in separate columns. After transposing, each month becomes a row and Sales and Returns become columns. This can make a time series easier to chart or combine with another month-by-month table.

The first row moves too

Transpose operates on the complete grid, including the first row. It does not treat the first record as a special header to leave in place. In the example above, the original headings Metric, January, and February move into the first output column alongside their corresponding values. Check whether that new orientation suits the spreadsheet or system where you plan to use it.

What happens when records have different widths?

A rectangular table has the same number of fields in every row. If some source rows are shorter, the transpose fills their missing positions with blank cells so the new grid can be formed. It does not invent values or discard extra fields; the widest source row determines the output row count.

Preview the rotated grid before saving

  1. Upload a CSV, TSV, or delimited TXT file, or paste its contents.
  2. Review the input dimensions and choose Transpose table.
  3. Check the output dimensions and inspect the complete transposed table.
  4. Copy the result or download it as a new CSV.

Comma, tab, semicolon, and pipe separators are recognized. Quoted fields can include delimiters, escaped quotation marks, and line breaks. The result downloads as comma-separated CSV. Files up to 50 MB are processed in your browser and are not uploaded to RomitCSV.

Questions about transposing CSV data

Does transpose keep the original header row at the top?

No. It rotates every row and column, so the original first row becomes part of the first output column. The preview uses generated column labels to show the resulting grid clearly.

Will transpose change the values in cells?

No. It changes where cells appear in the grid. Their contents move with them unchanged.

What happens to a short row?

Missing positions are filled with blank cells during the rotation. The widest input record determines the number of output rows.

Is transpose the same as sorting or pivoting?

No. Sorting changes the order of records, while pivoting groups or summarizes values. Transpose simply swaps the grid’s row and column positions.

Can I reverse the operation?

Yes. Transposing the result again restores the original rectangular grid, including any blanks added for short rows.

Is my file uploaded?

No. The data is read and transformed in your browser.
