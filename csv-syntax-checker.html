Check CSV quotes and row structure

    
A CSV can look normal in a text editor and still import incorrectly when a quoted value is incomplete or a row has an extra separator. This checker reads the file as delimited text and reports common quote mistakes and uneven row widths. It recognizes comma, tab, semicolon, and pipe separators from the first populated line.

    
Issues included in the report

    
    
      
  • Unclosed quoted field: a quoted value reaches the end of the file without a matching closing quote.
    • 
      
  • Quote inside an unquoted field: a quote appears after ordinary text has already started in the same field.
    • 
      
  • Unexpected text after a closing quote: non-whitespace characters appear between the closing quote and the next separator or line break.
    • 
      
  • Uneven row width: a record contains more or fewer fields than the header row.
    • 
    

    
Correctly quoted commas, escaped double quotes (""), and line breaks inside quoted fields are treated as part of the field. The report identifies the record number and explains the issue; it does not rewrite or repair the original file.

    
How to check a CSV file

    
  1. Choose a CSV or TSV file up to 50 MB, or paste delimited text into the paste box.
  2. Review the source table, then choose Check CSV.
  3. Use the row and detail columns to locate any issues and correct the source in your spreadsheet or editor.
  4. Copy or download the report if you need to keep or share the findings.

    
Processing happens in your browser; files and pasted data are not uploaded to RomitCSV. A clean result means no issues in these checks were found. It does not guarantee that every value matches your application's requirements.

    
Frequently asked questions

    
What does a valid result mean?
It means the checker found no unclosed or misplaced quotes and no data rows whose number of fields differs from the first row. It does not validate required values, data types, or business rules.

    
Why does a comma inside a value need quotes?
Without quotes, a comma is read as a field separator. Put the whole value in double quotes, for example "Paris, France".

    
Can this tool fix the CSV automatically?
No. It reports findings without changing the source so you can decide how each row should be corrected.

    
Why might a delimiter be detected incorrectly?
Detection uses the first populated line and supports comma, tab, semicolon, and pipe. If that line is irregular or uses another separator, the parser may not interpret the file as intended.
