What this comparison checks
Rows are matched by their complete sequence of parsed cell values. The tool ignores row order and accounts for duplicates, then provides one CSV containing the unmatched rows from each original file.
Make sure both files use the same column order. This comparison does not match records by a chosen ID, normalize capitalization, or trim whitespace.

  

  
CSV COMPARISON GUIDE
    
Compare two CSV files and find rows that differ
When two exports contain many records, a row comparison can show which entries were added or removed between them. This tool compares complete parsed rows and reports records found only in the first file and records found only in the second. The output keeps each source file's header row so you can inspect or reuse the results.

    
How row matching works
Row order does not affect the comparison. A row is matched when its cell values and column order are the same. Duplicate rows are counted: if one file has a row three times and the other has it twice, one unmatched occurrence appears in the first file's results. The header is not included in row matching.
The comparison is exact. Differences in capitalization, spaces, punctuation, or column order can make two otherwise similar rows count as different. If you need to compare records by an ID field or see cell changes at corresponding row positions, prepare the files first or use a diff tool designed for that comparison.

    
Compare two CSV files
  1. Choose exactly two CSV, TSV, or text files, or drop both into the upload area.
  2. Confirm the two filenames and select Compare CSV Files.
  3. Review the counts and side-by-side result tables.
  4. Download the rows unique to each input file.
Files are read locally in your browser and are limited to 50 MB each. The tool does not upload the files to a server.

    
Frequently asked questions
Does the order of rows matter?
No. Rows are compared by their cell values, so the same records can appear in a different order.
Are duplicate records included?
Yes. Duplicate counts are considered. Only the extra occurrences in either file appear as unmatched rows.
Does it match columns by their headings?
No. It compares each row's values in sequence. Put columns in the same order in both files before comparing.
Are spaces and capitalization normalized?
No. Matching is exact, so for example North and north are different values, as are cells with different whitespace.
Are headers included in the downloaded results?
Yes. Each result file keeps the header from its corresponding original CSV. Headers are excluded from record matching.
Can this show changed cells in matching rows?
This tool finds whole rows that are present in only one file. Use the CSV Diff Checker to compare cells by row position.
