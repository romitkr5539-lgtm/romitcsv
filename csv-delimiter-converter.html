Tool guide
CSV Delimiter Converter: what it does
The converter parses common comma, tab, semicolon, and pipe input, then writes the same cell values using the delimiter you choose. Fields containing delimiters, quotes, or line breaks are quoted and escaped.
How to use it
Choose a CSV or delimited text file, select an output separator, and run the converter. Use tab output for TSV files or match the separator expected by the application receiving the data.
What to check in the result
Automatic input detection works best when the first populated row has a consistent delimiter. If the input uses unusual quoting or inconsistent separators, verify the preview before using the download.
Frequently asked questions
Does it change the cell values?
No. It changes the separator and preserves parsed cell contents.
Will embedded commas remain part of a cell?
Yes. Fields are quoted when needed to protect delimiters and line breaks.
Can I convert to TSV?
Yes. Choose Tab as the output delimiter.
