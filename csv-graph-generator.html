Tool guide
CSV Graph Generator: what it does
The graph uses one selected numeric column for each axis and plots up to 40 rows with valid numeric values. Rows containing blank or non-numeric axis values are omitted.
How to use it
Load your file, choose numeric X and Y columns, and run the graph generator. Check that both selected fields contain values that can be read as numbers, such as 12 or 3.5.
What to check in the result
The graph shows association and distribution; it does not establish cause and effect. It uses rows in the CSV without sampling controls or regression calculations, so use a dedicated analysis tool for formal statistical work.
Frequently asked questions
Can I choose text for the X axis?
No. Both axes must contain numeric values.
Why are rows skipped?
A row is plotted only when both selected cells contain valid numbers.
Does the graph calculate correlation?
No. It visualizes points but does not calculate statistics.
