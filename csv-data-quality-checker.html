Review common CSV data quality problems
A file may open successfully and still contain issues that change results or cause an import to fail. Empty cells, repeated records, inconsistent field counts, stray spaces, and malformed quotes can be hard to notice by scanning a large CSV. This checker brings several common findings into one row-by-row report so you can decide what needs attention.

    
What the checker looks for
  • CSV quote syntax: unexpected text after a closing quote and quotes that are not closed.
  • Uneven row width: data records with a different number of fields from the header.
  • Blank rows: records where every field is empty or whitespace.
  • Missing cells: empty or whitespace-only values in individual fields.
  • Extra whitespace: non-empty values with spaces at the beginning or end.
  • Duplicate rows: later records that exactly repeat a previous complete record.

    
Findings are rule-based checks, not a universal quality score. A blank field or repeated row may be intentional in your data. The report identifies what matched each check and where it occurred; review the original context before changing a value.

    
How to check CSV data quality
  1. Choose or drop a CSV, TSV, or plain-text file up to 50 MB, or paste delimited data.
  2. Review the parsed source table and confirm that the first row contains the headings.
  3. Scan the summary counts and inspect each finding by row and type.
  4. Copy or download the report, then make any corrections in your original file.

    
Rows are numbered with the header as row 1 and the first data record as row 2. Some records can have more than one finding, so the total finding count may be higher than the number of affected rows. The checker reports issues but does not edit the CSV. Your file is processed in your browser and is not sent to the RomitCSV server.

    
Frequently asked questions
Does the checker repair the file?
No. It creates a report and leaves the original data unchanged. You can review findings and decide how to make corrections.
Why can the finding count exceed the number of rows?
A single row can have several issues, such as a missing value and extra whitespace in another cell. Each issue is listed separately.
Are repeated rows always errors?
Not necessarily. The tool reports exact repeated complete rows, but you should decide whether a repetition is unwanted in your particular dataset.
How are missing values identified?
Empty cells and cells containing only whitespace are flagged. Text markers such as N/A or NULL are treated as values.
How are row numbers counted?
The header is row 1, so the first data record is row 2. The report uses those CSV row positions to help locate the record in the preview or original file.
Does it check whether values have the correct business meaning?
No. It checks common structural and formatting patterns. It cannot know every rule for your dataset, such as valid ranges, required categories, or whether a blank is allowed.
