Tool guide
CSV Data Visualizer: what it does
For each column, the visualizer counts nonblank cells and blank or whitespace-only cells across data rows. The summary includes these counts so you can compare completeness between columns.
How to use it
Select a CSV or TSV file and run the visualizer. The chart helps locate columns with missing values; inspect the original records before deciding whether a blank represents an error, an optional field, or unknown data.
What to check in the result
A completeness count cannot explain why a value is missing or whether a value is valid. It does not detect incorrect formats, outliers, or duplicate records. Use the missing-values checker or data-quality checker for additional checks.
Frequently asked questions
Does it count the header as data?
No. Counts are calculated from rows below the header.
Are whitespace-only cells missing?
Yes. Cells containing only whitespace count as blank.
Does the chart validate values?
No. It reports filled and missing counts only.
