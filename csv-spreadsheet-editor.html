Spreadsheet-Style CSV Editor

Edit CSV in a Spreadsheet Grid

Edit CSV or TSV data in a familiar grid. Update cells and headings, add or remove rows and columns, then download a CSV copy. Your data stays in your browser.

Edit CSV Data in a Spreadsheet-Style Grid

This editor gives CSV and TSV data a familiar grid, so you can correct a value or reshape a table without editing commas and quotation marks by hand. A sample table appears when the page opens. Choose a file to replace the sample with your own data; the selected file is read in your browser.

Change a Cell or Its Heading

Click a cell to edit its text, or edit a column heading in the top row. When you select a cell, the bar above the grid shows its address, such as C4, and its current value. You can change the value in that bar or directly in the cell. The fx label identifies the cell-value field; it is not a spreadsheet formula calculator.

The editor treats cell contents as text. A value such as 00127 stays as entered instead of being automatically converted to the number 127. If you open a file without column headings, its first record is used as the heading row, so check that row before downloading.

Add, Remove, and Browse Table Structure

Use Add row to append a blank data record or Add column to create a new field with blank cells. Each row or column has a delete control. The grid displays 25 data rows per page; use the page arrows to move through the rest of the file. Changes apply to the complete table, including records on pages you are not currently viewing.

There is no search or sort control on this page. If you need to find a record or sort by a column before editing, open the CSV Table Viewer and choose its edit option.

Download a Copy to Keep Your Changes

Choose Download CSV to create a file containing the full table and your edits, including rows and columns added or removed on other pages. The editor does not write back to the original file on your device and does not autosave your changes in a separate file. Download your copy before leaving or refreshing the page.

The downloaded file uses commas between fields and has a .csv extension, even if you started with a tab-separated TSV file. CSV is plain text: this editor does not retain workbook colors, fonts, number formats, or multiple sheets, and it does not evaluate formula-like values. Values containing commas, quotes, or line breaks are quoted when the CSV is written.

File Limits and Browser Handling

CSV and TSV files up to 50 MB are accepted. The editor detects a common separator—comma, semicolon, tab, or pipe—from the first non-empty line. File reading and editing happen in your browser; the contents are not sent to a server by this tool. Large files may take longer to open and use more memory.

Use the CSV Preview Tool to inspect a sample before editing, or the standard CSV Editor for its simpler table-editing workflow.

Questions About the Spreadsheet Grid

Can I edit a CSV without installing spreadsheet software?

Yes. Open a CSV or TSV file here, make changes in the grid, and download the edited table as a CSV file.

What does the cell address bar do?

It shows the selected cell address and lets you edit that cell value. It does not calculate spreadsheet formulas.

Will the download include rows on other pages?

Yes. Download CSV contains the complete table, including edits and structural changes made on any page.

Does the editor overwrite the file I opened?

No. It creates a CSV download; the original file on your device is not changed. Download the edited copy before closing or refreshing the page.

Will a TSV download stay tab-separated?

No. The downloaded copy is comma-separated CSV with a .csv file extension.

Can I search or sort the grid?

This spreadsheet editor does not include search or sort controls. Use the CSV Table Viewer to search or sort records.

Are my file contents uploaded?

No. This page reads and edits the selected file in your browser and does not send its contents to a server.
