CSV AGGREGATION GUIDE

Get a useful summary from one CSV column

When a spreadsheet export contains a long list of amounts, durations, or quantities, a single summary can make the data easier to understand. The CSV Data Aggregator calculates a count, sum, average, minimum, or maximum for a field you choose, while leaving the source table intact for review.

Use Count non-empty values to see how many records have something entered. Choose Sum to total numeric entries, Average to find their arithmetic mean, or Minimum and Maximum to find the smallest and largest valid numbers.

How numeric cells are treated

For numeric calculations, blank cells and text that cannot be read as a number are skipped. Values such as 12, -3.5, and 0 are included. A field with no numeric values has no numeric result rather than a misleading zero. Count non-empty values counts populated cells, whether their contents are numeric or text.

Steps to summarize your data

  1. Open a CSV, TSV, or delimited TXT file, or paste the data.
  2. Choose the column you want to summarize.
  3. Select Count, Sum, Average, Minimum, or Maximum.
  4. Review the result and copy or download the small CSV summary.

The original data is shown in a table above the result. Processing stays in your browser, and files up to 50 MB are supported.

Questions about CSV column summaries

Does Count include blank cells?

No. Count non-empty values counts only cells that contain text or a number.

Are text values included in Sum or Average?

No. Sum, Average, Minimum, and Maximum use cells that contain valid numbers. Blank cells and other text are skipped.

What does Average calculate?

It adds the valid numbers and divides by how many valid numeric cells were found.

Will the tool change my source file?

No. It creates a separate summary and leaves the original table unchanged.

Is the CSV uploaded?

No. The selected file is read and processed in your browser.
