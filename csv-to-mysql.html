Practical guide
How CSV to MySQL INSERT Statements works
The first row supplies column names. Identifiers use MySQL backticks, apostrophes in values are escaped, and rows are grouped into INSERT batches. Values remain text rather than inferred numbers or dates.
Convert your file
Enter a table name such as customers or app.customers. Blank cells become empty strings by default; select Write empty cells as NULL to emit SQL NULL. These values differ in MySQL, so match the choice to your target columns.
Before using the output
The converter does not connect to MySQL or create a table. Confirm table and column names, review the output, and test it against a safe database before importing important data.
Frequently asked questions
Does it generate a CREATE TABLE statement?
No. It generates INSERT statements only.
Will dates and numbers be converted?
No. They are quoted as text; MySQL may coerce values when inserting into typed columns.
Are blank cells NULL by default?
No. They are empty strings unless you enable the NULL option.
