Replace Text Across CSV Rows and Columns

When a product name, city, status, or category changes, the old value can be repeated throughout an export. This CSV find and replace tool updates those matches in one pass. Load a CSV, TSV, or text file and its contents appear in the table; enter the text to find and what should replace it, then run the change and review the updated cells.

For example, replacing Basic Plan with Starter Plan updates both the standalone name and that phrase when it appears inside a longer cell value:

FIND
Basic Plan
REPLACE WITH
Starter Plan
AFTER REPLACEMENT
Product,Status
Starter Plan,Active
Starter Plan Plus,Active

What the search changes

The tool looks for the text inside every parsed cell, including the first row used for column headings. It replaces all matches, not just the first one in a cell. The search is literal, so characters such as ., +, and brackets mean those exact characters; they are not treated as wildcards or regular expressions.

Matching ignores uppercase and lowercase by default. For instance, searching for mumbai can also match Mumbai. Turn on Match case when you only want the exact letter case you entered. The replacement itself is inserted as written, including symbols such as $&.

Load a file, review the table, and replace

  1. Choose a CSV, TSV, or TXT file up to 50 MB, or paste delimited text into the editor. After a file loads, the upload area collapses and the CSV table takes its place. Select Edit CSV text if you want to work directly with the raw text.
  2. Enter the phrase to find and the replacement. Leave the replacement empty if you want to delete each occurrence; the search field must contain text.
  3. Choose whether matching should respect letter case, then select Find and Replace.
  4. Read the updated table and row and column counts. Download the result as a separate CSV when it looks right.

The table makes it easier to scan headings and neighboring values after a change. It shows up to 200 data rows and 40 columns at a time; the downloaded file contains the full result. Wide tables can be scrolled horizontally.

Check for partial matches before downloading

This tool replaces a matching substring wherever it appears. Searching for Plan, for example, can also change Planner; it does not offer whole-word matching. A distinctive phrase is safer when codes, notes, or longer names share some of the same characters.

Each replacement stays within its existing cell. The tool does not move values between columns, change the rest of a cell’s capitalization, remove duplicate records, or validate your column types. It reads the file in your browser, leaves the original file untouched, and creates a new comma-separated CSV for download. TSV and other supported delimited input is also exported as CSV.

FIND AND REPLACE CSV FAQ

Find and Replace CSV: Common Questions

Does it replace text in column headings?

Yes. The first row is included in the search, so a matching column heading is changed along with matching cell values.

Will it replace a phrase inside a longer value?

Yes. Matching is by substring, not whole word. A search for Basic Plan also matches the start of Basic Plan Plus.

Can I remove text instead of replacing it?

Yes. Keep the replacement field empty to delete each occurrence. Enter a search term; an empty search is not allowed.

Can I make the search case-sensitive?

Yes. Enable Match case. Otherwise, the search matches the same letters regardless of uppercase or lowercase.

Does it support symbols such as periods or dollar signs?

Yes. Search text is treated literally, and replacement text is inserted exactly as typed, including symbols.

Does the table show my whole file?

The on-page preview is limited to 200 data rows and 40 columns. Download the CSV to get all rows and columns.

Is my CSV uploaded to a server?

No. The file is read and processed in your browser. The original file is not overwritten.

Keep the original and check the exported CSV

Preview the changed values before downloading, especially when the search text is short or appears in notes and identifiers. The download contains the complete updated data even when only part of it fits in the table preview. If you need individual edits instead of a repeated replacement, use the CSV Editor. For whitespace or Unicode cleanup, try Normalize CSV Data; use the CSV Validator to check file structure.
