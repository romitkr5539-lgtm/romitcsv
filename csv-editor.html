Free Online CSV Editor

Edit Your CSV Files

Change cell values and headings, add or remove rows and columns, then download the full table as a CSV file. Your data stays in your browser.

Drop a CSV file here to edit or Supports CSV, TSV · Max file size: 50MB

Edit CSV Cells, Rows, and Columns Online

Use the CSV Editor for practical changes to a table: correct a value, rename a heading, remove an unused field, or add a row to an export. The page starts with sample data so you can see the grid. Choose a CSV or TSV file to replace the sample with your own records.

Cells and column headings are edited directly in the table. For example, you can correct a product price or change a heading before sending the file to another system. The editor keeps values as text, so a value such as 00127 is not automatically converted into a number.

Make Changes in the Table

  1. Choose Browse CSV File or drop a CSV or TSV file into the upload area. Files up to 50 MB are accepted.
  2. Review the headings and records. The first row is treated as the column headings; if your file has no header, its first data record will be used as headings.
  3. Click a cell or heading and type to change its text. Use Add row for a blank record or Add column for a new field.
  4. Use the × control beside a row or column heading to remove it. If the table continues onto more pages, use the page arrows to reach the records you want to edit.
  5. Select Download CSV when you are ready to save your changes.

What Happens When You Download

Download CSV creates a new file from the full table, not just the 25 rows currently visible. It includes changes made on other pages, added rows and columns, and deletions. The editor does not save changes back into the original file on your device, so download a copy before leaving or refreshing the page.

The download is comma-separated CSV with a .csv extension, even if you opened a tab-separated TSV file. CSV is plain text: the editor does not calculate formula-like values or retain workbook colors, fonts, number formats, or multiple worksheets. Any formula expression in the file is handled as text. Values that need quotes because they contain commas, quotes, or line breaks are quoted in the downloaded CSV.

File Support and Browser Processing

The editor accepts CSV and TSV files up to 50 MB. It reads the file in your browser and keeps the table data there while you work; the contents are not sent to a server by this tool. The editor detects a common separator from the first non-empty line, including commas, semicolons, tabs, and pipe characters. As with other browser tools, very large files can take longer to open and may use more memory.

This page is for changing cell values and table structure. To find or sort records without editing them, use the CSV Table Viewer. For checks on row structure, use the CSV Validator.

Questions About Editing CSV Files

Can I edit a CSV file online without installing software?

Yes. Open a CSV or TSV file in the browser, edit its table, and download the changed data as a CSV file.

Will the download include rows on other pages?

Yes. Download CSV includes the complete table, including rows that were not visible on the current 25-row page, along with your edits.

Can I change the column names or add and remove fields?

Yes. Edit a heading directly, add a column for a new field, or remove a column with its × control. You can also add or remove data rows.

Does the editor save over my original file?

No. It creates a downloadable CSV copy. Download it before leaving the page if you want to keep your changes.

Will a TSV file remain tab-separated?

No. The downloaded file is comma-separated CSV with a .csv extension, even when the source file was TSV.

Does the editor keep spreadsheet formulas and formatting?

No. CSV and TSV do not carry workbook formatting. A formula-like value may remain in the file as text, but the editor does not evaluate it.

Is my file uploaded?

No. The selected file is read and edited in your browser; this editor does not send its contents to a server.
