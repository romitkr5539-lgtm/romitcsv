See what is inside each CSV column
A CSV can hold a few columns or thousands of records, and issues such as blank cells or repeated values are easy to miss by scrolling. The CSV Statistics Generator creates a compact summary for each column so you can quickly see how much data is present, how varied it is, and whether its values look numeric.

    
What the report includes
  • Non-empty and missing values: counts filled cells and blank cells beneath each heading. Whitespace-only cells are treated as blank.
  • Unique values: counts distinct non-empty values exactly as written. Differences in capitalization or spaces count as different values.
  • Numeric minimum, maximum, and average: calculated from cells that can be read as finite numbers. Non-numeric and blank cells are left out of these calculations.

    
The first row is treated as the header, and only rows after it are included as data. The report describes the parsed values; it does not modify or clean the original file. If a column mixes numbers and text, the numeric figures summarize only the values that can be interpreted as numbers.

    
How to generate CSV statistics
  1. Choose or drop a CSV, TSV, or plain-text file up to 50 MB, or paste delimited data.
  2. Review the source table to confirm that the first row contains the expected column names.
  3. Read the row and missing-cell totals, then inspect each column’s detailed statistics.
  4. Copy or download the report as CSV if you want to keep the summary.

    
The file is read and analyzed in your browser. It is not sent to the RomitCSV server. For checks such as uneven row widths, quote problems, or duplicate headers, use the CSV Validator.

    
Frequently asked questions
Does the generator count the header as a data row?
No. The first record is treated as the column headings. Statistics are calculated from the records that follow it.
How does it count missing values?
Empty cells and cells containing only whitespace are counted as missing. A value such as 0 is not missing.
Are unique values case-sensitive?
Yes. The report compares the values as written, so North and north count as two distinct values. Leading or trailing spaces also remain part of a value.
Why are numeric statistics blank for a column?
The column may have no values that can be parsed as finite numbers. Numeric minimum, maximum, and average ignore blank and non-numeric cells.
Can I paste data instead of uploading a file?
Yes. Paste comma-, tab-, semicolon-, or pipe-delimited text and choose Generate statistics. The first row will be used as headings.
Does this change my CSV?
No. This tool creates a separate report and leaves the source data unchanged.
