Identify the likely type of each CSV column
Knowing whether a column contains numbers, dates, labels, or mixed values can help catch import mismatches before they reach a database or analytics tool. The Column Data Type Detector examines non-empty cells under each heading and suggests a type based on the values it finds.

    
Types the detector can report
  • Integer: whole-number values without a decimal or exponent.
  • Number: decimal or exponent-form values, or a mix of whole and decimal numbers.
  • Date: common year-month-day values that the browser can parse as dates.
  • Boolean: values such as true/false or yes/no.
  • Text: values that do not match the recognized numeric, date, or boolean forms.
  • Mixed: non-empty values that resolve to more than one type, such as an integer and an unrelated text label.
  • Empty: a column with no non-empty values.

    
Type detection is an estimate, not a guarantee about the intended meaning of a field. For example, an ID like 001 looks numeric even if your application treats it as a text identifier. Date recognition is limited to common year-month-day formats. The report also shows the number of non-empty values used for each column’s inference.

    
How to detect CSV column types
  1. Choose or drop a CSV, TSV, or plain-text file up to 50 MB, or paste delimited data.
  2. Check that the first row of the preview contains the expected column headings.
  3. Review each inferred type and the non-empty value count.
  4. Copy or download the report if you need to share the results.

    
The detector reads the file and creates a separate report; it does not change values or assign a database schema. Your data is processed in your browser and is not sent to the RomitCSV server. For broader type, missing-value, and sample-value details, see the CSV Data Profiler.

    
Frequently asked questions
Does the detector change my CSV values?
No. It only reads the data and reports a likely type for each column.
Why is a numeric-looking ID detected as a number?
The detector uses the content of the cells. It cannot know that values like 00123 are identifiers that should remain text, so review the suggestion against your data’s intended meaning.
What makes a column Mixed?
A column is labeled Mixed when its non-empty values fit more than one recognized type. Blank cells are excluded from type inference.
How are dates detected?
The detector recognizes common year-month-day formats that can be parsed as dates. Other date formats may be classified as text.
What happens to blank columns?
A column with no non-empty data values is labeled Empty. Blank cells are not used when inferring other columns’ types.
Can I check pasted data?
Yes. Paste comma-, tab-, semicolon-, or pipe-delimited text and choose Detect data types. The first row is used as the headings.
