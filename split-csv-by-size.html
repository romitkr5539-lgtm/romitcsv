Split a CSV into Parts by File Size

Some upload forms and data systems limit the size of each file you can send. This CSV size splitter breaks one file into smaller, sequential parts using a target size in kilobytes. It keeps each data record together and repeats the heading row at the start of every part, so the files remain recognizable on their own.

Set the target size in KB

Enter the maximum target size for each part. The tool measures the generated CSV text in bytes and groups complete records until adding another row would pass the target. It then starts the next part with the original header and continues with the next record.

A target is a best effort when a single row or the repeated header is larger than the limit. The splitter will not break a record across files, so an oversized row stays intact in its own part and may make that file exceed the requested size. UTF-8 characters, quoting, and delimiters also affect the final byte count.

Preview and download the size-based parts

  1. Choose or drop one CSV, TSV, or supported delimited text file up to 50 MB.
  2. Set the desired maximum part size in KB.
  3. Select Split by File Size and review the part sizes and table preview.
  4. Download one part or save all parts together as a ZIP archive.

Parts remain in source order and use numbered filenames. Each downloaded file includes all its rows and a header. The preview displays a page of data from the selected part; it does not limit the downloaded content.

What is preserved when a file is split

Rows are not sorted, filtered, or deduplicated. Every source data record appears once, in its original order. Quoted commas, quotation marks, and line breaks stay inside their fields. TSV and supported delimited TXT input is converted to comma-separated CSV output.

The source file is left unchanged. Processing happens in your browser; file contents are not sent to the RomitCSV server. The splitter supports up to 10,000 output parts. If your target would create more, increase the size limit.

CSV SIZE SPLITTER FAQ

Questions About Splitting CSV by File Size

Will every part stay under my target size?

Usually, but not if a single record or the repeated header is larger than the target. Records are kept whole, so an oversized row can make a part exceed the limit.

Are rows broken apart to meet the size?

No. A full row stays together in one output file.

Does each part include the column headings?

Yes. The source header is repeated in every part.

What does KB mean here?

The size field is entered in kilobytes, with 1 KB treated as 1,024 bytes for the target calculation.

Will the parts keep their original order?

Yes. Records are written sequentially, and each numbered part follows the previous one.

Can I download all the parts at once?

Yes. Select the ZIP option to save every part in one archive, or download the part currently selected.

Can I split TSV files by size?

Yes. TSV and supported delimited text files are accepted; the output files use CSV formatting.

Are my files uploaded?

No. The file is processed in your browser and remains unchanged on your device.

Check each part against the destination limit

Review the displayed sizes before uploading the parts to another service. If one part is over the target because it contains a long record or heading, raise the target size or check that service’s exact file-size rule. If you want a fixed number of records per output instead, use the CSV row splitter.
