Find the separator in your delimited file

    
A delimiter is the character between fields in a text table. Commas are common in CSV files, while TSV files use tabs; semicolons and pipes are also used by some exports. If an application opens every row in one column, or splits a field at the wrong place, checking the separator is a useful first step.

    
What the detector measures

    
The tool checks the first non-empty line and counts commas, tabs, semicolons, and pipes outside quoted text. The separator with the largest count is reported as the likely delimiter, and the report shows the count for each candidate. If counts tie, the detector keeps its candidate order: comma, tab, semicolon, then pipe.

    
This is a quick estimate based on one line, not a full-file consistency check. If the file has one column, irregular rows, or a quoted header that contains separators, inspect the preview and counts before importing it.

    
Use the delimiter detector

    
  1. Choose a CSV, TSV, or TXT file up to 50 MB, or paste delimited text.
  2. Review the source table and the likely separator shown in the summary.
  3. Compare candidate counts in the report if the result is unexpected.
  4. Copy or download the count report, then select the matching import option in your spreadsheet or data tool.

    
Your source data is read in the browser and is not changed. The detector supports comma, tab, semicolon, and pipe candidates.

    
Common questions

    
Does the detector check every row?
No. It counts separators on the first non-empty line. Use the full table preview to inspect your data, and use CSV Validator to check row widths and other structural issues.

    
Why does it say no delimiter was found?
The first non-empty line may contain only one field, or it may use a separator outside the four supported candidates. Check the source text and the reported counts.

    
Are commas inside quoted values counted?
No. Characters inside a pair of double quotes are ignored when counting candidate separators.

    
Does detecting a delimiter change my file?
No. The tool reports the counts and likely separator. It does not rewrite or convert the source data.

    
Can I paste data instead of uploading a file?
Yes. Paste the header and a few rows, then select Detect pasted data. The table and report appear on the page.
