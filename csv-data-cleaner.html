Clean a CSV in One Pass

    
A contact export can arrive with spaces around names, spacer rows between groups, repeated records, and a column that nobody filled in. Fixing each issue by hand takes time and makes it easy to miss one. The CSV Data Cleaner runs a set order of cleanup steps and gives you a preview before you save the result.

    
Here is a small example. The heading and name have extra spaces, the Optional field is empty, Bob appears twice, and one row has no values. After cleanup, the useful records remain in a narrower table.


    

      
BEFORE
 Name ,Email,Optional
 Ada , ada@example.com ,   
Bob,bob@example.com,
Bob,bob@example.com,
,,

      
AFTER
Name,Email
Ada,ada@example.com
Bob,bob@example.com

    

    
The output above reflects the cleaner’s steps in order. This is a general cleanup pass; inspect the preview if your file has fields where spaces, repeated records, or blank columns carry meaning.


    
What the Cleaner Does, in Order

    
    
      
  1. Trim cell edges. Leading and trailing whitespace is removed from every field, including the first row of headings. Spaces inside a value are left alone.
    2. 
      
  2. Remove fully blank data rows. A row is removed when every cell is empty or whitespace after trimming. The first parsed row is kept as the header.
    3. 
      
  3. Remove exact duplicate rows. The first copy is kept. All fields must match after trimming; comparison is case-sensitive, so Acme and ACME remain separate.
    4. 
      
  4. Drop empty columns. A column is removed when every remaining data cell beneath its heading is blank. Its heading is removed with it.
    5. 
    

    
Because trimming happens first, values that differ only by spaces at their edges can become duplicates. The cleaner does not merge near-matches, standardize capitalization, or decide whether two differently formatted names refer to the same person.


    
Choose a File, Paste Data, and Review

    
Drop a CSV, TSV, or text file into the upload area, choose Browse CSV File, or paste delimited text. Select CSV Data Cleaner to run the four steps. The result summary shows row and column counts before and after; review the preview, then select Download Cleaned CSV.

    
The parser recognizes comma, tab, semicolon, and pipe separators, and keeps quoted values together. The output is standard comma-separated CSV. Completely empty physical lines are skipped while parsing; rows made from delimiters, such as ,,, are parsed and removed if all their cells are blank.


    
Know What Will Change Before You Run It

    
This cleaner is designed for a broad first pass, so all four actions run together in the same order. There are no switches for keeping duplicates or preserving empty columns. If you only want one operation, use its individual tool instead.

    
Duplicate checking compares the entire row, not a selected ID column. Records with one different value are kept. The tool also does not validate that every record has the same number of fields as the header, convert dates or numbers, or repair unclosed quoted fields. Use the CSV Validator to inspect structure separately.


    

      
CSV DATA CLEANER FAQ

      
Questions About This Cleanup Pass

      
Which copy of a duplicate row is kept?
The first copy is kept and later rows with the same parsed cell values are removed. Matching happens after outer whitespace is trimmed and is case-sensitive.

      
Does it remove a row if only one cell is blank?
No. A row is removed only when all its cells are blank after trimming. A partially filled row stays.

      
Will it trim my column headings?
Yes. The first parsed row is treated as headings and its values are trimmed. Headings for columns removed as empty are dropped too.

      
Can I keep empty columns or duplicate rows?
This combined cleaner always removes exact duplicate rows and columns that are empty throughout the data. Use a focused tool if you need to preserve either.

      
Can I clean TSV or paste text?
Yes. Open CSV, TSV, or TXT files up to 50 MB, or paste delimited text. The result downloads as comma-separated CSV.

      
Does the preview show every row?
Long previews are shortened at about 7,000 characters. The downloaded CSV contains the full cleaned result.

      
Are my files uploaded?
No. The selected file is read and processed in your browser; its contents are not sent to a server.

    


    
Saving the Cleaned File

    
The download is a new CSV; your original file is not overwritten. CSV stores plain text values, so spreadsheet styling, formulas, and multiple worksheets are not included. Files are processed in your browser, and very large files can take longer depending on your device.


    
Pick a More Focused Tool

    
Use Remove Duplicate Rows, Remove Empty Rows, or Remove Empty Columns when you want to choose one cleanup action. See the CSV Validator for structural checks.
