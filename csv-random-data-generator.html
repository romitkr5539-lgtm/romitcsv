Tool guide
CSV Random Data Generator: what it does
Enter one field per line using name:type, such as email:email or age:integer. The generator supports text, integer, number, email, date, name, and city types and creates up to 10,000 rows.
How to use it
Set a row count, edit the schema, then click Generate. The output includes a header row. Email values use the reserved example.com domain, making them suitable for demonstrations rather than contacting real people.
What to check in the result
Generated values are synthetic test data, not a statistically representative sample. Names and locations come from small built-in lists, and the tool does not guarantee uniqueness except where its pattern makes values distinct.
Frequently asked questions
Can I control the exact values?
The tool selects generated values from its built-in patterns and sample lists; it does not accept custom value lists.
Are generated emails real?
They use example.com and are for demonstration only.
How many rows can I create?
The generator accepts 1 to 10,000 data rows per file.
