Check CSV column names before you import

    
The first row of a CSV usually tells the receiving application what each field contains. A blank heading can leave a column hard to identify; duplicate names may cause an importer to confuse fields; and extra spaces can make a heading fail to match the name an application expects. This checker reviews the header row and lists each issue by column.

    
What the header checker finds

    
  • Blank headings: a column name is empty or contains only whitespace.
  • Duplicate headings: names that match after trimming outer spaces and ignoring letter case, such as Email and email.
  • Leading or trailing spaces: spaces around a heading’s visible name. The checker reports this separately even when it also finds a duplicate.

    
The first CSV row is treated as headings. The checker does not rename columns or change the source file, and it does not check data row widths or quote syntax. Use CSV Syntax Checker for those structural checks.

    
How to check your headings

    
  1. Upload a CSV or TSV file up to 50 MB, or paste delimited text.
  2. The checker scans the first row automatically and shows the complete source table with a summary of any header issues.
  3. Review the highlighted headings and the findings list.
  4. Copy or download the report, then make corrections in your original spreadsheet or editor.

    
Files and pasted text are processed in your browser. A clean report means no blank, duplicate, or padded header names were found; it does not validate data values in the remaining rows.

    
Frequently asked questions

    
Does the checker change or fix my column names?
No. It reports issues and leaves the source data unchanged so you can choose appropriate names.

    
Are duplicate headings checked without regard to case?
Yes. For example, City and city are reported as duplicates. Outer spaces are trimmed for duplicate comparison and reported separately.

    
Does it check every row in the file?
The source table is shown for review, but header findings are based on the first row only. Use CSV Syntax Checker to check row widths and quotation marks.

    
Can I check pasted data instead of uploading a file?
Yes. Paste comma-, tab-, semicolon-, or pipe-delimited text and select Check pasted data. The page then displays the source table and header findings.
