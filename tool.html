Choose the right tool for your task.

Open, search, and edit a table

Use the CSV Table Viewer to inspect rows and columns, search values, and sort a table. To focus on a particular field or record, use the CSV Column Viewer or CSV Row Viewer. To change cell values and save an updated file, open the CSV Editor.

Clean, check, or organize rows

Remove duplicate rows with the CSV Cleaner, check a file's structure with the CSV Validator, or combine multiple CSV files and split a large file into smaller parts.

Convert CSV data to another format

Convert CSV data to HTML, JSON, Excel, XML, YAML, Markdown, TSV, plain text, PDF, or SQL. Convert XML, YAML, TSV, JSON, and Excel back to CSV.

Check the structure before converting

CSV stores table rows as text, with fields separated by a delimiter such as a comma. A header row is commonly used for column names. Quoted fields may contain commas or line breaks, so review the preview and output when a file uses special characters or has missing values.
