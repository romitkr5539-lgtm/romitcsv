GROUP BY GUIDE

Summarize repeated categories in a CSV

Exports often repeat the same region, product, team, or status on hundreds of rows. Group By gathers records with the same value into one category, so you can see how many records belong to it or how a numeric field adds up.

For example, a sales export with one line per order can be grouped by Region. Count rows to compare order volume, or choose Revenue and calculate a sum to see sales totals. The result is a concise summary table that is easier to share or use in a report.

Choose a grouping field and calculation

Select the column whose repeated values define each group. The tool keeps categories in the order they first appear, including a separate group for blank category cells. That makes missing labels visible instead of silently dropping their records.

Count rows includes every record in the group. Sum and Average use valid numeric cells from the selected value column. Blank cells and text that is not a number are skipped for those calculations; a group without any numeric values has an empty result.

When Group By is useful

Use it to compare order counts by status, add revenue by region, or calculate average response time by support team. Group By creates one summary level at a time. If you need two category fields across a grid, use the CSV Pivot Table Generator instead.

How to create a grouped CSV

  1. Upload a CSV, TSV, or delimited TXT file, or paste its contents.
  2. Choose the category column and select Count rows, Sum values, or Average values.
  3. For a numeric calculation, select the value column to summarize.
  4. Inspect the grouped results, then copy or download the summary as CSV.

The source table remains available above the result for comparison. All processing happens in your browser; the file is not sent to RomitCSV. Files up to 50 MB are supported.

Questions about grouping CSV data

What does Count rows count?

It counts every data record in each category, whether or not the selected numeric field has a value.

How are sum and average calculated?

Only valid numeric cells in the selected value field are included. Blank or non-numeric cells are ignored.

What happens to blank category values?

Rows with an empty grouping value are kept together in their own blank category.

Does this change my original file?

No. Group By creates a separate summary, and your source data remains unchanged.

Can I group by more than one field?

This tool summarizes by one field. For a two-category cross-tab, use the Pivot Table tool.

Is my file uploaded?

No. The data is read and summarized locally in your browser.
