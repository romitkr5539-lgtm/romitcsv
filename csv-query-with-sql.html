Tool guide
Query CSV with SQL: what it does
Write a query against the virtual table named data, for example SELECT Name, City FROM data WHERE City = 'Pune' ORDER BY Name LIMIT 20. The tool supports selected columns or *, one basic WHERE condition, ORDER BY, and LIMIT.
How to use it
Choose a CSV or TSV file, enter your query, then run it. Column names must match the header text. Text comparisons are exact except LIKE, which supports % and _ wildcards; numeric comparisons use numeric values.
What to check in the result
This is a small in-browser query helper rather than a complete SQL engine. It does not support joins, aggregates, expressions, or multiple predicates. Treat CSV values as text unless using a numeric comparison.
Frequently asked questions
Can I use JOIN or GROUP BY?
No. The current query tool supports SELECT, one WHERE condition, ORDER BY, and LIMIT.
How do I select every column?
Use SELECT * FROM data.
Can I download the query result?
Yes. Use Download Result to save the matching rows as CSV.
