CSV SQL QUERY GUIDE
    
Query CSV data with SQL
When a CSV is too large or detailed to inspect manually, a focused query can help narrow it down. This tool treats the uploaded file as a temporary table named data. Write a supported SELECT query to choose columns, filter rows, sort them, or limit the number of results. The matching records appear in a table and can be downloaded as a new CSV.

    
SQL features supported
Use SELECT * to return every column, or list header names separated by commas. The query parser supports one basic WHERE condition, ORDER BY with optional ASC or DESC, and LIMIT. Conditions include equality and comparison operators, IS NULL, IS NOT NULL, and LIKE with % and _ wildcards.
Text equality checks compare the cell contents exactly. LIKE matching is case-insensitive. Numeric comparison operators use numeric values; rows with values that are not numeric do not match those comparisons. CSV cells are otherwise treated as text.

    
Run a query on your CSV file
  1. Choose or drop one CSV, TSV, or delimited text file.
  2. Enter a query using data as the table name and the CSV headings as column names.
  3. Select Run SQL Query to view the result table.
  4. Copy the results or download them as CSV.
Files up to 50 MB are processed in your browser. The tool does not upload data or connect to a database.

    
Know the limits
This is a small query helper, not a full SQL engine. It does not support JOIN, GROUP BY, aggregate functions, expressions, multiple WHERE conditions, or subqueries. Column names must match the header text. If your data contains spaces or special characters in headings, use the exact heading as the selected column name where the supported syntax allows it.

    
Frequently asked questions
Can I query a CSV with JOIN or GROUP BY?
No. The current tool supports selected columns, one simple WHERE condition, ORDER BY, and LIMIT. It does not combine datasets or calculate aggregates.
How do I select all columns?
Use SELECT * FROM data.
Are CSV values treated as numbers?
Values are read as text. Numeric comparison operators parse values as numbers only for that comparison.
Does the query change my original CSV?
No. The query creates a separate result that you can copy or download.
Can I download matching rows?
Yes. After the query completes, use the Download CSV button to save the result table.
Is my data uploaded?
No. The selected file is read and queried locally in your browser.
