Split a CSV into Smaller Files by Row Count

A large export can be difficult to upload, email, or review as one file. The CSV Splitter breaks a CSV or TSV into smaller parts based on the number of data rows you choose. Load a file, set the rows per part, inspect each part, then download one part at a time or bundle them all in a ZIP.

The first row is treated as the column heading row and is always included in the first part. You can choose whether that heading row is repeated in every later part. The row limit counts data rows, so a part with 500 data rows and a repeated heading contains 501 CSV rows.

Choose a row limit that suits the next step

Set Rows per part to the maximum number of records you want in each output. For example, a file with 2,350 data rows split at 1,000 rows produces three parts: 1,000 rows, 1,000 rows, and 350 rows. The order of the records is preserved, and each part continues where the previous one stopped.

The row limit is independent of file size. A thousand long text records may produce a larger part than a thousand short records. If a receiving system sets a size limit rather than a row limit, check the downloaded parts before uploading them.

Decide whether later parts need the header

Repeat header in every part is enabled by default. This makes each later file easier to understand or import on its own because it starts with the column names. The first part keeps the header either way. Turn the option off when another process will combine the pieces and needs only one header across the full dataset.

With the option off, part 1 contains the heading row and its data rows; later parts contain data rows only. The preview still displays the source headings above the selected part so you can read its columns.

Preview and download the split parts

  1. Select a CSV, TSV, or TXT file up to 50 MB, or drop it into the upload area.
  2. Enter the maximum number of data rows per part and choose whether to repeat the header after the first part.
  3. Select Split CSV. Use the part selector or arrow buttons to inspect each part and its original row range.
  4. Download the selected part, or download all parts together as a ZIP archive.

The on-page table shows the first 100 data rows in the selected part. The part files and ZIP contain all rows, including rows outside that preview. Output files use comma-separated CSV even when the source was TSV or another supported delimiter.

What happens to values and row order

Splitting creates sequential chunks; it does not sort, filter, or remove duplicate records. Quoted commas, quotation marks, and line breaks stay within their original fields. Blank data rows are preserved. Every data record appears in one part, in the same order as the source.

The tool works in your browser. It does not upload the source file or change it on disk; each downloaded part is a new file. If a CSV contains an unclosed quoted field, the tool reports the formatting problem rather than splitting a misread table.

CSV SPLITTER FAQ

Questions About Splitting CSV Files

Does the row limit include the header?

No. The number is the maximum data rows in a part. The first part always includes the header, and later parts include it only when the repeat-header option is on.

Will every part have column headings?

The first part always does. Turn on Repeat header in every part to add the same headings to each later part.

Can I download all parts at once?

Yes. Select Download all parts (ZIP) to save every part in one archive, or download only the part currently shown.

How many parts can I create?

The splitter supports up to 10,000 parts per file. If the chosen row limit would create more, increase the limit before splitting.

Can I split TSV files?

Yes. CSV, TSV, and supported delimited TXT files can be split. The output parts are comma-separated CSV files.

Are rows sorted or removed?

No. Records remain in their original order. The splitter does not filter or remove duplicate rows, and blank data rows are preserved.

Is there a file size limit?

Each input file can be up to 50 MB.

Are my files uploaded?

No. The file is parsed and split in your browser. The original remains unchanged.

Check a few parts before sharing them

Review the part selector, row ranges, and final part before sending the files to another person or system. The last part is often shorter than the others. If the receiving process expects headings in every file, leave the repeat-header option enabled; if it expects one header for the complete dataset, turn it off for later parts.
