Practical guide
How CSV to SQLite INSERT Statements works
The header row becomes quoted column identifiers, and subsequent rows become INSERT values. Apostrophes are escaped. Rows are grouped in batches of up to 500 to keep larger outputs practical.
Convert your file
By default, empty fields are inserted as empty strings. Select Write empty cells as NULL to emit SQL NULL instead. Those values behave differently in queries and constraints, so choose intentionally.
Before using the output
This page produces SQL text; it does not open a database or create the destination table. Check the schema and generated values, then test on a copy when the data is important. SQLite may coerce values according to column affinity.
Frequently asked questions
Can it create a database file?
No. It generates statements for your SQLite application or command-line tool.
Does it infer column types?
No. Values are quoted as text and handled by the destination table.
How are blanks represented?
As empty strings by default, or as NULL when you select the option.
