CSV TO SQLITE GUIDE
    
Generate SQLite INSERT statements from CSV
To move rows from a CSV file into an existing SQLite database, you can load the data with SQL INSERT statements. This converter uses the first CSV row as the column list and makes one or more INSERT statements for the remaining rows. Choose a table name, review the parsed data, and copy or download the SQL for use with your SQLite application or command line.

    
What the generated SQLite SQL contains
Table and column names are enclosed in double quotes, with embedded quote marks escaped. Text values are enclosed in single quotes and apostrophes are doubled so they remain part of the value. Cells are emitted as text; SQLite applies the destination column affinity when the statements execute. The converter does not infer types or generate a CREATE TABLE definition.
Rows are grouped into INSERT batches of up to 500 records. Blank cells become empty strings by default. Select Write empty cells as NULL to output SQL NULL instead. These values differ in SQLite: an empty string is text, while NULL represents a missing or unknown value.

    
Set the destination table and inspect the headings
The table name defaults to csv_data. You can enter a schema-qualified name such as main.customers; each identifier part is quoted separately. The first row becomes the column names. Blank or repeated headings are made unique, short records are padded with empty values, and extra cells are retained under generated names.

    
Convert a CSV file to SQLite SQL
  1. Drop a CSV, TSV, or text file into the upload area, browse for one, or paste delimited data.
  2. Review the CSV table and choose the destination table name.
  3. Set how empty cells should be represented.
  4. Select Generate INSERT statements, inspect the SQL, then copy or download it.
Files are processed locally in your browser. This page does not open a database, create a table, check the schema, or run the statements. Confirm that the destination columns and constraints match your data, and try the output with a copy of the database before importing important records.

    
Frequently asked questions
Does this create or modify a SQLite database file?
No. It generates SQL text. Run the statements using your SQLite application or command-line tool to add data to a database.
Does it generate a CREATE TABLE command?
No. The destination table must already exist with columns that match the generated column list.
Are numbers and dates converted to SQLite types?
No. Values are quoted as text. SQLite may apply the column affinity during insertion, but you should check that the values are valid for the destination columns.
How are blank cells represented?
They become empty strings by default. Turn on the NULL option to emit SQL NULL values instead.
Are quotation marks in values and identifiers escaped?
Yes. Apostrophes in values are doubled, and embedded double quotes in identifiers are escaped by doubling them.
Is my file uploaded or executed?
No. Your browser reads the selected file locally. The generated statements are displayed as text and are not executed by this page.
