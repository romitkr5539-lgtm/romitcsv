Tool guide
CSV Column Mapper: what it does
The tool starts with source headings as suggested targets. Choose a target name for each source column or skip it, and add or edit target headings one per line. A target can map to no more than one source column.
How to use it
Upload a CSV, edit the target heading list, set each mapping, then run the mapper. The resulting file follows your target order; target headings without a selected source receive empty cells.
What to check in the result
Mapping changes column names and order, not the values themselves. Check that every required field is mapped correctly and that your target system accepts the chosen headings.
Frequently asked questions
Can two source columns map to the same target?
No. Each target heading can be assigned to at most one source column.
What happens to an unmapped target?
Its output cells are blank.
Does mapping alter cell values?
No. It moves values into the selected target columns.
