Get a quick profile of your CSV data
Before analyzing or importing a CSV, it helps to know whether columns contain dates, numbers, labels, or a mix of values. The Data Profiler reviews the records under each heading and summarizes the patterns it can infer. Its report pairs that overview with missing and distinct value counts and examples from the data.

    
What the column profile shows
  • Inferred type: a best-effort label such as Integer, Number, Date, Boolean, Text, Empty, or Mixed. Type is inferred from non-empty cells in each column.
  • Non-empty and missing: counts filled cells and blanks beneath the first-row heading. Whitespace-only cells are treated as missing.
  • Unique values: counts distinct non-empty values as written. Differences in case or surrounding spaces remain distinct.
  • Sample values: shows up to three distinct, non-empty examples to help you interpret the inferred type.

    
Type labels are suggestions based on cell contents, not a schema guarantee. A column with numbers and text is marked Mixed; date recognition follows common year-month-day formats. The profiler doesn’t change values or flag every data-quality issue.

    
How to profile a CSV
  1. Choose or drop a CSV, TSV, or plain-text file up to 50 MB, or paste delimited data.
  2. Check that the first row of the preview contains the headings you expect.
  3. Review the overview cards and column-by-column report.
  4. Copy or download the report as CSV if you want to share or keep it.

    
Your file is processed in your browser and is not sent to the RomitCSV server. For row-width, quote, or header problems, use the CSV Validator. For numeric ranges and averages, see the CSV Statistics Generator.

    
Frequently asked questions
How does the profiler decide a column’s type?
It looks at non-empty values in the column. If all values fit one recognized type, it reports that type. If values fit different types, it reports Mixed. Empty columns are labeled Empty.
What does Mixed mean?
Mixed means the non-empty cells do not all fit the same inferred type. For example, a column containing 24 and unknown is mixed.
Are blank cells included in the type inference?
No. Blank and whitespace-only cells count as missing, but they don’t affect the inferred type.
How are unique values counted?
Distinct non-empty values are compared as written. Letter case and leading or trailing spaces are preserved, so East and east count separately.
Does the profiler modify my CSV?
No. It only reads the data and creates a separate profile report. Your source file stays unchanged.
Can I profile pasted data?
Yes. Paste comma-, tab-, semicolon-, or pipe-delimited content and select Profile data. The first row is treated as the headings.
