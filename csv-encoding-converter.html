Tool guide
CSV Encoding Converter: what it does
The converter reads the selected file using the chosen or detected source encoding, then encodes the decoded text in the selected output format. A BOM, when present, helps some spreadsheet programs identify the encoding.
How to use it
Select the source encoding if auto-detection reads characters incorrectly, choose the output encoding, then run the conversion. Open the downloaded file in the target application and verify accented characters and symbols.
What to check in the result
Encoding conversion cannot restore characters already corrupted in the source. Auto-detection mainly recognizes Unicode byte-order marks; legacy encodings may need to be selected explicitly.
Frequently asked questions
Which output encodings are available?
UTF-8, UTF-8 with BOM, and UTF-16 little-endian.
Does auto-detection identify every legacy encoding?
No. It recognizes common Unicode markers; choose a source encoding explicitly when needed.
Why do characters still look wrong?
The source may already be corrupted or its original encoding may have been selected incorrectly.
