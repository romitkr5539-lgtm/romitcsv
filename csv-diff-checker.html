How to read the report
Each report row identifies the CSV row and column position, then shows the value from the first and second files. A blank value means that file has no cell at that position.
This is a positional comparison. If a row is inserted or the records are sorted differently, following rows may appear changed. Align the files first for a meaningful cell-by-cell review.

  

  
CSV DIFF GUIDE
    
Compare CSV files cell by cell
A CSV diff report helps review two versions of a table when you need to know which values changed at each position. This tool compares corresponding rows and columns, then lists the row number, column name, and values from both files for every difference. It also reports extra rows and columns when the files have different dimensions.

    
How positional CSV comparison works
The checker compares the header row and data rows in their current order. If a cell matches in both files, it is skipped. If the values differ, the report includes both values. When a cell or row is missing from one file, that side is shown as blank. The report is a separate CSV, so the source files remain unchanged.
Row order matters. Inserting a record near the beginning can make many later rows appear different because positions shift. Sort or align the exports before comparing them. This checker does not match records by an ID column, ignore case, or normalize whitespace.

    
Run a CSV diff
  1. Choose exactly two CSV, TSV, or text files, or drop both files into the upload area.
  2. Confirm the filenames and select Compare CSV Files.
  3. Review the highlighted values from each file in the report table.
  4. Copy the report or download it as csv-diff-report.csv.
Each file can be up to 50 MB. Files are read locally in your browser and are not uploaded to a server.

    
Frequently asked questions
Does this compare records by a key column?
No. It compares cells by row and column position. Use the separate Compare Two CSV Files tool to find complete rows that occur in only one file regardless of row order.
Does the header row appear in the report?
Yes. The first row is compared like other rows, so changes to column names are included.
What happens if the files have different sizes?
Extra rows and columns are checked too. Any cells present on only one side are shown with a blank value for the other file.
Does row order affect the results?
Yes. Values are compared at the same row and column positions. Sort both files consistently before comparing if their records are ordered differently.
Are the original files modified?
No. The tool creates a separate report and leaves both source files unchanged.
Is my data uploaded?
No. The selected files are read and compared locally in your browser.
