Tool guide
CSV Anonymizer: what it does
Choose one or more columns to anonymize. The same original value receives the same replacement within that column; blank cells remain blank. Each selected column has its own replacement sequence.
How to use it
Load a CSV, select the columns that contain identifying information, and run the anonymizer. Review the output to confirm the selected columns are appropriate before sharing it.
What to check in the result
This simple substitution does not guarantee de-identification. Rare combinations, unselected columns, dates, free text, and external information may still identify people. Do not treat the output as legally anonymized or safe for every disclosure.
Frequently asked questions
Are repeated values kept consistent?
Yes. Within a selected column, repeated values receive the same replacement.
Are blank cells changed?
No. Blank or whitespace-only values are left as they are.
Does this guarantee privacy?
No. It only replaces chosen cell values and cannot assess re-identification risk.
