JSON CONVERSION GUIDE

Convert JSON data to CSV

JSON is useful for applications and APIs because it can represent structured records. CSV is often easier to open in spreadsheet software, import into a database, or share with someone who needs a simple table. This free JSON to CSV converter turns a JSON object or a list of objects into rows and columns, with a preview before you copy or download the result.

How the JSON to CSV converter works

Start with a JSON file or paste JSON text into the input box. The converter reads the data in your browser, checks that it contains a supported object structure, and builds a table from the object properties. Review the preview, choose whether to include a header row and how to handle null or nested values, then select Convert. You can copy the resulting CSV or save it as a .csv file.

  1. Upload a .json file or paste valid JSON.
  2. Review the detected fields and adjust the conversion options.
  3. Select Convert to refresh the preview, then copy or download the CSV.

Supported JSON structure

The converter accepts either one JSON object or an array of JSON objects. An array is the usual choice when converting a collection of records: each object becomes a CSV row, and its properties become columns. For example, an array of people with name, email, and city properties becomes a table with those fields.

Objects in the same array do not need identical properties. The converter collects field names in the order they first appear and leaves a cell empty when a record has no value for a field. Arrays of numbers or strings, nested arrays as top-level records, and empty arrays are not supported as rows because they do not provide a consistent set of named columns.

Headers, null values, and nested data

The Include header row option adds the field names as the first CSV row. This is useful for spreadsheets and imports that expect column labels. Turn it off when the destination expects data rows only.

By default, a JSON null becomes an empty CSV cell. You can turn off Empty cells for null values to write the word null instead. Primitive values such as numbers and booleans are written as text, as CSV does not preserve JSON data types. If an object contains arrays or nested objects, Serialize nested values as JSON keeps that cell as a JSON string. Disable it only if you want the browser's basic text representation of nested values.

CSV escaping and preview

Commas, quote marks, and line breaks inside a value need special handling in CSV. The converter wraps such values in double quotes and doubles any quote marks inside them, so they remain part of one cell when opened by a CSV-aware app. The preview shows up to ten data records to keep large files manageable; downloading still includes the complete converted output.

CSV is a flat format, so it cannot retain every feature of JSON. Nested information is kept as text when JSON serialization is enabled, while object relationships, data types, and deeper structure are not converted into separate tables automatically. If your destination needs those details, keep the original JSON or transform the structure before exporting.

Frequently asked questions

Can I convert JSON to CSV without uploading a file?

Yes. Paste a JSON object or array of objects into the paste box and choose Convert pasted JSON. You can also edit the JSON in the workbench after it loads.

What JSON input does this converter accept?

It accepts one object or a non-empty array where every item is an object. Arrays of primitive values and arrays of arrays do not provide named fields for CSV columns and are not accepted.

How are different object properties handled?

Fields are combined across records in first-seen order. If a record does not contain one of those fields, its CSV cell is left empty.

Does the CSV keep numbers and booleans as their original types?

No. CSV stores cell values as text. Spreadsheet programs may infer types when opening the file, but that behavior depends on the program.

How are commas and quotation marks handled?

Values containing commas, quotes, or line breaks are enclosed in quotes, and embedded quotes are doubled according to common CSV escaping rules.

Will the preview show every converted row?

The preview displays up to ten data records. Use Download CSV to save the complete converted result.

Is my JSON sent to a server?

This page reads and converts the selected or pasted data in your browser. The tool's conversion code does not upload the JSON to a conversion service.

What if the JSON is invalid or deeply nested?

The converter reports a parse or structure error for invalid input. Nested objects and arrays inside a record can be serialized into a JSON string, but they are not expanded into additional CSV columns automatically.
