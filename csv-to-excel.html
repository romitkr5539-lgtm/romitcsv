CSV TO XLSX GUIDE

Convert CSV to an Excel spreadsheet

CSV files are easy to exchange, but they do not include a worksheet name, filters, or spreadsheet cell types. This online CSV to Excel converter reads a CSV or TSV file and creates a genuine .xlsx workbook with one worksheet. You can also paste delimited text, review every row in the table, choose how values are read, and download the workbook.

When an XLSX workbook is useful

Use XLSX when the next step involves working in Excel or another spreadsheet app, sharing a file with a named worksheet, or filtering a table with column headings. The exported workbook keeps the rows and columns from the parsed source text. When the header option is enabled and there is more than one row, the worksheet includes an autofilter over the data range.

The conversion does not add charts, formulas, multiple worksheets, or visual formatting to the data. It creates a straightforward worksheet from the delimited values so the file is ready for further spreadsheet work.

Choose the right separator and header setting

Auto-detect is selected by default. If the columns do not line up in the preview, choose the separator used by the source: comma, semicolon, tab, or pipe. Automatic detection checks the first non-empty line, so choosing the separator yourself can help when that line contains quoted text with punctuation.

Leave First row contains headers selected when the first line contains field names. Turn it off if the file starts with a data record. The preview then labels columns as Column 1, Column 2, and so on; these labels are for the preview, and are not inserted into the workbook.

Keep values as text or convert simple numbers

By default, values remain text. This helps preserve identifiers and codes such as 00123, which can lose leading zeros if treated as a number. Turn on Convert number-like cells to numbers when you want simple values like 42, -8, or 3.14 stored as numeric cells for calculations. Dates, currency, percentages, and locale-specific number formats are not inferred automatically.

Check the displayed table before exporting, especially when the source uses an unusual delimiter or mixes text and numeric values. The table includes all parsed records in a scrollable view, and the download is built from the same complete set of rows.

Convert a CSV or TSV file

  1. Drop a .csv or .tsv file into the upload area, browse to select one, or paste delimited text.
  2. Review the table and select the separator, worksheet name, header, and number options you need.
  3. Choose Download Excel (.xlsx) to save the workbook.

The upload limit is 50 MB. Excel worksheets support up to 1,048,576 rows and 16,384 columns; the converter reports an error if the input exceeds either worksheet limit.

Frequently asked questions

Does this make an XLSX workbook or just rename my CSV?

It creates an Excel-compatible .xlsx workbook containing a worksheet populated with the parsed CSV or TSV rows. It does not simply change the file extension.

Can I convert CSV to Excel without uploading a file?

Yes. Paste comma-, tab-, semicolon-, or pipe-separated text in the paste box. The result opens in the same table and export workspace as an uploaded file.

Will the workbook keep leading zeros?

Yes, with number conversion turned off, values are written as text, which preserves leading zeros. The number option only converts simple number formats and leaves values such as 00123 as text.

Does the table show every row?

Yes. The table is scrollable and contains all parsed rows. The worksheet download also includes all rows, subject to Excel's worksheet size limits.

Can I convert a tab-separated file?

Yes. Choose a TSV file or paste tab-separated text, then select Tab or use Auto-detect if the first non-empty line makes the separator clear.

Is my CSV uploaded to a server?

The selected file or pasted text is parsed in your browser, and the workbook is generated there. The XLSX library is loaded from jsDelivr, so an internet connection is required for the export feature.

Can I add formulas, formatting, or multiple sheets?

This converter creates one plain worksheet from the source table. It does not create formulas, custom cell styling, charts, or additional worksheets.

Keep working with the converted data

To convert an Excel workbook back into a text file, use Excel to CSV. For JSON output, try CSV to JSON, or browse all CSV tools.
