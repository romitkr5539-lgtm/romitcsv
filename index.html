What is a CSV File?

A CSV (Comma-Separated Values) file is a simple text file that stores data in a tabular format. It's widely used to exchange data between applications, databases and spreadsheets.

Learn more about CSV →

Common questions.

What is a CSV file?

A CSV file stores tabular data as plain text, with values separated by commas or another delimiter.

How do I open a CSV file?

Choose a CSV file above to preview its rows and columns directly in your browser.

Can I convert CSV to JSON?

Yes. RomitCSV includes a CSV to JSON converter for turning tabular rows into JSON data.

Are uploaded CSV files stored?

The homepage reads your selected file in the browser and temporarily saves it in browser storage so the CSV Table Viewer can open it. The viewer clears that pending copy after loading.
